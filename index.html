  • Crossfire를 열어야 할 때 opening 발언권을 다시 주는 등 진행 단계를 혼동했습니다.
  • 10초 남음 안내 대신 발언을 바로 종료하거나 closing으로 넘어가는 오류가 있었습니다.

기준선과 해석

동일 Gemini 3편의 timing 기준선: always silent 0/28, every-trigger deadline oracle 27/28, on_pause 24/28.

on_pause는 실제 음성 감지가 아닌 주석상 발화 종료시각을 이용한 oracle입니다. 정답 사회자 구간의 빈틈이 정적 입력에 남아 있어 유리한 조건입니다.

방법과 한계

  • 정답 MOD 발화는 입력에서 제외하고 PRO/CON 음성을 원래 시간표대로 실시간 전송했습니다. 토론자는 모델 발화에 반응하지 않습니다.
  • WAV VAD: 20ms, −38dBFS, 최소 200ms 발화, 600ms 침묵 경계. Reference clock과 동일 rubric/scorer를 사용했습니다.
  • 내용은 모델명을 가린 fresh Codex 검수입니다. Human gold 또는 직접 청취 검증으로 표현하지 않습니다.
  • Gemini 기본 실험은 49/62개, Proactive는 25/31개 음성 구간만 전사와 일대일 연결됐습니다. 나머지는 내용 미확인입니다.
  • 2.5 기본은 v1beta, Proactive는 v1alpha입니다. API 버전도 달라 Proactive 기능 하나의 인과 효과로 단정할 수 없습니다.
  • GPU와 Gemini는 voice reference, context, 발화 제어 조건이 다릅니다. 남성 입력 음량이 낮은 데이터 문제도 보존된 상태입니다.
  • 음성 재배포 권한 확인 전이라 이 공개판에는 WAV·전사 원문·voice reference를 포함하지 않았습니다. 로컬 듣기 리포트는 별도 보존되어 있습니다.
